# Sources — gta6-trophy-guide-01

Every fact in this guide rests on one of the seven sources below. Trophy
names, descriptions and grades are PlayStation's own words as published;
the guides are this entry's own words, written from these sources and
cited per trophy in `app/data/trophies.json`. The data file carries a
top-level `sources` registry (ids [1]–[7]); each trophy carries its own
`sources` list of registry ids, and each numbered step cites a registry
id, so one number means the same source everywhere in the guide.

Retrieval: all seven sources below were last retrieved and verified on
20 November 2026. Every trophy is backed by at least two of them;
coverage is [1] 55/55, [2] 55/55, [3] 54/55, [4] 1/55, [5] 55/55,
[6] 53/55, [7] 5/55. The Source matrix tab in the app shows which source
backs which trophy.

## The watch list (story-linked windows)

- **[7] TechWiser — All GTA 6 Main (Story) and Side (Strangers & Freaks) Missions Walkthroughs** —
  https://techwiser.com/gta-6-missions/
  The mission walkthroughs behind the five-strand watch list: the
  stranger chains behind five hidden trophies have windows linked to
  story progress, so each chain should be started as soon as it unlocks.
  TechWiser is the only source that gives that warning, and the guide
  says so. It covers exactly the five watch trophies — Andy (Chapter 3,
  Lucia-only), Kenton (marked in Chapter 1, calls after Island Dreams),
  Billy (Thrillbilly Mudclub, after Chapter 2's Coffee Break), Randy and
  Tyrone — and nothing else in this guide. Retrieved 20 November 2026.

## The one disagreement, shown honestly

Positive Mental Attitude (id 28) is the only trophy where the sources
split. PowerPyx and GTABase count **18 meditation spots** for the trophy,
while the 100% checklist counts **15**; eGamers notes the two sources
disagree. PowerPyx also adds it is still unconfirmed whether the Chapter 1
spot is required at all — its author did the spot and then earned the
trophy. The guide does not pick a side: the trophy's counter is set to
18, the steps tell the reader to do the Chapter 1 spot and aim for 18,
and the detail panel shows the disagreement box with both versions and
the sources behind each. If the trophy pops at 15, the reader is done
early; if not, 18 covers it.

## What is NOT a source here

- No Rockstar Games logo, official artwork, box art or game screenshot is
  used anywhere in this entry.
- No guide text is copied from any of the sources above: each guide is
  written in this entry's own words, and the source is cited beside it.
- Where the sources disagree or say "unconfirmed", this guide says so
  rather than picking a side silently. The game launched 19 November 2026;
  details may change as players crack the last five triggers.
